物流システム v3
================

目的
----
スマホでQRを連続撮影し、同日中にGmailを経由してPCへ一方向に移行し、PCで納品日・ホール名（店舗名）・商品名を付与してA4印刷する運用を想定しています。

運用フロー
----------
【スマホ】
1. ① QR連続登録でQRを撮影
2. QR全体・傾き・歪み・サイズを厳しくチェック
3. 同じQRは重複登録しない
4. 今回登録分を確認
5. 「PCへ送信」からGmail転送

【Gmail】
6. 指定アドレスへQR画像を添付したメールが届く
7. PCで添付画像を保存

【PC】
8. ② QR一覧・情報付与で「Gmailから受信したQR画像を読み込む」
9. 納品日・店舗名・商品名を一括付与
10. ③ 印刷準備で納品日＋店舗名（両方必須）で絞り込み
11. 必要なQRだけ選択
12. A4 4個/6個でPDF作成
13. 既存の読み取りシステムで読み取る

重要
----
・v3本体はGitHub Pagesで動作します。
・スマホとPCのデータは自動同期しません。Gmailが一方向の受け渡し経路です。
・Gmail自動送信にはGoogle Apps Script（GAS）のWebアプリを1つ用意します。
・Gmail添付は25MB/通が上限なので、v3は1バッチ約10MBを目安に自動分割します。
・PC側ではGmailから保存したPNG/JPEGを複数選択して一括取り込みできます。
・QR画像は業務データとしてURL等を保存せず、重複判定用にQRの内容を内部キーとして使います。

Gmail送信の初期設定
--------------------
1. Google Apps Scriptで新規プロジェクトを作成
2. 同梱の Code.gs を貼り付け
3. CONFIGの以下を変更
   TRANSFER_TOKEN: 長いランダム文字列
   DEFAULT_TO: QRを受信するGmailアドレス
4. デプロイ > 新しいデプロイ > ウェブアプリ
   実行するユーザー: 自分
   アクセスできるユーザー: 全員
5. ウェブアプリURLをコピー
6. v3の「設定 > スマホ→PC データ移行」にURL・送信先・同じトークンを入力して保存

セキュリティ上の注意
--------------------
GAS Webアプリを「全員」に公開するため、TRANSFER_TOKENは推測しにくい長い文字列にしてください。URLとトークンは第三者に公開しないでください。

GitHub Pages
------------
index.html / manifest.webmanifest / sw.js / icon-192.png / icon-512.png / README.txt をリポジトリ直下へ配置してください。

現状の保存方式
----------------
PC側・スマホ側それぞれのブラウザでlocalStorageを使います。PC側を本管理、スマホ側を一時保存として扱います。
