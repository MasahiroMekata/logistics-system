【v5.2 変更点】
・ヘッダーの説明文を削除しました。
・スマホ側のメニュー名を「① QR連続読み込み」に変更しました。
・手順1でQRコードを読み取り、画像ではなくURLだけを保存します。
・手順2はQR画像のカード表示からURLのリスト表示に変更しました。
・手順3はURLをTXT添付メールとして指定先へ送信します。GASのCode.gsを設定して再デプロイしてください。
・PC側では受信したTXTを読み込み、URLからQRコード画像を再生成します。



【v5 追加対応】
・ホールマスタは「本店名,ホール名」を1行ずつ登録します（例：DM,京都東店）。情報付与では本店名を選ぶと、その本店のホールだけが候補になります。
・スマホは読み取ったURL一覧をGAS経由でTXT添付メールとして送信します。PCはTXTを読み込み、URLからQRコード画像を再生成します。GASのCode.gsを更新して再デプロイしてください。
・印刷済み履歴はホールごとに直近2回のPDF作成分を保持し、3回目のPDF作成時に最古の履歴を自動削除します。PDF内のページ数・QR枚数ではなくPDF作成回数で管理します。
・印刷対象の絞り込みはホール名のみです。PDF上部はホール名、その下に納品予定日を表示し、各QRの下に商品名を表示します。

【GAS設定】
Code.gs内のTRANSFER_TOKENとDEFAULT_TOを設定し、Webアプリとして再デプロイしてください。既存デプロイURLを維持する場合も、新バージョンをデプロイする必要があります。
