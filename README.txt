物流システム v2 改良版

主な仕様
- QR連続登録：QR全体が枠内、十分な大きさ、正面、低歪み、3フレーム安定認識を満たした場合のみ保存
- 同一QRは自動保存しない（QR内容は重複判定用の内部キーとしてのみ利用）
- 今回登録分を全選択／選択削除／全削除
- 店舗：入力・検索・選択（店舗マスタ）
- 商品：一度入力して選択QRへ一括付与、過去の商品名を候補化
- 納品日：カレンダーから選択して一括付与
- 情報付与画面の入力欄は一覧フィルタではないため、入力中にQRが消えない
- 印刷準備：納品日＋店舗で絞り込み、必要なQRだけ選択
- A4：4個＝2列×2行、6個＝2列×3行
- PDFはブラウザ側でページを画像化してPDF化するため、日本語文字化けを抑制
- PDF作成後は印刷済みへ移動、戻す／完全削除が可能
- JSONバックアップ／復元
- GitHub Pages向けPWA

注意
現在はlocalStorage方式のため、データは同じブラウザ内で保持されます。スマホで登録したQRをPCで共有するには、次段階でSupabase等の共有DB接続が必要です。
