物流システム v4

【構成】
スマホ作業
  ① QR連続登録
    手順1：QRコードを登録
    手順2：登録したQRコードを確認
    手順3：QRコードを送信

PC作業
  ② 情報付与
    手順4：QRコード読込
    手順5：QRコード一覧 / ラベルの付与
  ③ 印刷準備
    手順6：印刷するQRコード選択
    手順7：PDF作成
  ④ 印刷済み

共通
  ⚙ 共通設定

【スマホ】
QRは連続カメラ読み取りのみ。画像アップロード追加はありません。
QR全体が枠内・正面・十分な大きさ・低歪みで、同じQRが3フレーム連続で安定した場合に保存します。
同じQRは重複保存しません。
手順2ではQRを1つずつ選択でき、全選択・選択解除・選択QR削除ができます。
手順3では「QRコードを送信」だけを使用し、手順2で選択したQRをGAS経由でGmailへ送ります。

【PC】
手順4ではGmailから保存した複数のQR画像を一括読込できます。
手順5では納品日・ホール・商品を選択QRへ一括付与できます。
列順は「納品日 → ホール → 商品」です。
手順6では納品日とホールを必須条件として印刷対象QRを選択します。
手順7ではA4縦PDFを作成します。4個(2×2)または6個(2×3)。
ページ上部に納品日・ホール名を大きく表示し、QRは印刷可能範囲でできる限り大きく配置します。QR下には商品名のみ表示します。

【GAS】
google-apps-script/Code.gs の CONFIG に転送トークンと送信先を設定し、Webアプリとしてデプロイしてください。
実際の送信先等は「⚙ 共通設定」に入力します。
Gmailの1通あたりの添付上限を考慮し、v4はおおむね8MB単位で分割して送信します。

【GitHub Pages】
リポジトリ直下に index.html / manifest.webmanifest / sw.js / icon-192.png / icon-512.png を置きます。
Settings → Pages → Deploy from branch → main → /(root)。
更新後に古いService Workerが残る場合はブラウザで強制再読み込みしてください。
