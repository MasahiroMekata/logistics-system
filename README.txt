物流システム v2

主な機能
- QR連続スキャン：検出するたび自動登録
- 同一QRの重複登録防止：QR内容を内部キーとして利用（業務データとしては管理しない）
- QR画像を検出位置から切り出して保存
- 店舗・商品・納品日を後から一括付与
- 店舗マスタの検索・選択
- 商品名を一度入力して選択QRへ一括付与
- 日付を選んで選択QRへ一括付与
- 納品日＋店舗で印刷対象を絞り込み
- 印刷前にチェックボックスで必要なQRだけ選択
- A4縦PDF：4個=2列×2行、6個=2列×3行
- 上部中央に納品日、各枠にQR＋店舗＋商品
- 複数ページ自動生成
- PDF作成後は「印刷済み」へ移動
- バックアップ書き出し・読み込み

注意
- 現在はlocalStorage保存です。スマホとPCで同じデータを共有するにはクラウドDB等が必要です。
- 初回利用時はjsQR/jsPDFをCDNから読み込むためインターネット接続が必要です。
- カメラ利用にはHTTPSまたはlocalhostが必要です。
- 実運用前に「撮影→QR切り出し→PDF→A4印刷→既存システムで読み取り」を実機で確認してください。
