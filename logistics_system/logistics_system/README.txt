# 物流システム v0.1 — PWA版

## できること
- スマホカメラでQRコードを撮影
- QRコード部分を検出・切り出し
- 店舗名、商品名、納品日を登録
- 店舗・納品日で絞り込み
- A4印刷用PDFを作成
- ブラウザのlocalStorageへ端末内保存
- PWAとしてホーム画面に追加

## PWAとして使う方法
PWAは通常、HTTPSまたはlocalhostで配信する必要があります。
このフォルダをWebサーバーに配置してスマホからHTTPSで開いてください。

例：
1. GitHub Pages / Vercel / Netlifyなどに配置
2. HTTPSのURLをスマホで開く
3. 「ホーム画面に追加」が表示されたら追加

※ iPhoneではブラウザの「共有」→「ホーム画面に追加」から追加できる場合があります。

## v0.1の重要な仕様
QRコードの中身を業務データとして保存するのではなく、QRコード画像として保存します。
店舗・商品・納品日は現時点では手入力です。
データはブラウザのlocalStorageに保存されるため、別端末とは共有されません。

## 注意
QR検出とPDF生成用ライブラリはCDNから読み込むため、初回利用にはインターネット接続が必要です。
実運用前に、実際のQRで「撮影→切り出し→PDF→A4印刷→既存システムで読み取り」を確認してください。

## v0.2 の変更点（Web版移植時の修正）
