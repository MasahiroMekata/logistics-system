手順1

QRコードを読み取る

できること

  • スマホのカメラでQRコードを読み取り、URLを一覧に保存します。

操作方法

  1. 「スキャン開始」を押します。
  2. QRコードをカメラに向けます。
  3. 読み取れると、画面に緑の表示が出ます。
  4. 終わったら「停止」を押します。
  5. 次は、手順2でURLを確認します。

注意点

  • 初めて使うときは、カメラの使用を「許可」してください。
  • 決められたサイトのURLだけを保存します。ほかのQRコードは保存しません。
  • 同じURLは、二重に保存しません。
  • 暗いときは「ライトON」、小さいときは「拡大」のバーを使えます（スマホによっては表示されません）。

手順2

読み取ったURLを確認する

できること

  • 読み取ったURLを一覧で確認し、送るURLを選びます。
  • 要らないURLを削除できます。

操作方法

  1. 送るURLの行を押して、チェックを入れます。行のどこを押しても選べます。
  2. すべて選ぶときは「全選択」、やめるときは「選択解除」を押します。
  3. 要らないURLは、チェックを入れて「選択URL削除」を押します。
  4. 選び終わったら、手順3へ進みます。

注意点

  • 手順3で送られるのは、チェックを入れたURLだけです。
  • 削除すると、一覧から消えます。消す前に、もう一度確認してください。
手順3

URLをメール経由で送信する

できること

  • 選んだURLを、メールでPCに送ります。

操作方法

  1. 手順2で、送るURLを選びます。
  2. 「URL送信」を押します。
  3. 「送信完了」と出たら、PCでメールを確認します。
  4. うまく送れないときは、「接続テスト」を押して、接続を確認します。

注意点

  • 先に「設定」で、送信先などを入力して保存してください。
  • 送ったURLは、手順2の一覧から「② 送信済み」へ移ります。
  • 「GASの応答を確認できませんでした」と出たときは、メールが届いたか確認してください。届いていないときだけ、もう一度送ります。もう一度送ると、メールが二重に届くことがあります。

手順4

送信済みURLを確認する

できること

  • メールで送ったURLの記録を見ます。
  • メールが届かなかったとき、手順2に戻して、もう一度送れます。

操作方法

  1. やり直したいURLの行を押して、チェックを入れます。
  2. 「手順2に戻す」を押します。
  3. 手順3で、もう一度「URL送信」を押します。

注意点

  • 送ってから24時間たつと、記録は自動で消えます。元に戻せません。
  • 「全選択」「選択解除」でまとめて選べます。
手順5

URLからQRコードを作成する

できること

  • URLが書かれたファイルを読み込んで、QRコードを作ります。

操作方法

  1. 「URL一覧を一括読込」を押します。
  2. URLが書かれたファイル（txtまたはcsv）を選びます。ファイルは、まとめて何個でも選べます。
  3. 「読み込み完了」と出たら、手順6へ進みます。

注意点

  • 同じURLのQRコードは、二重に作りません。
  • 表示された「追加・重複・読み取り不可」の件数を確認してください。「読み取り不可」は、URLが見つからなかったファイルの数です。
まだURLは読み込まれていません。
手順6

納品日・本社名・ホール名・商品名を付ける

できること

  • QRコードに、納品日・本社名・ホール名・商品名を付けます。
  • 付け終わったQRコードは、「④ 印刷準備」へ進めます。

操作方法

  1. 付けたいQRコードのチェックを入れます。「全選択」でまとめて選べます。
  2. 納品日・本社名・ホール名・商品名を入力または選択します。
  3. 「納品日を付与」「本社名・ホール名を付与」「商品名を付与」のどれかを押します。
  4. すべて付け終わったら、QRコードのチェックを入れて「付与完了にする」を押します。
  5. 付与完了にしたQRコードは、「④ 印刷準備」へ移ります。

そのほかの操作

  • QRコードの画像を押すと、そのQRコードだけを大きく表示します（専用の読み取り機で読むときに使います）。
  • 大きく表示している間は、左右の矢印ボタン（またはキーボードの ← →）で、隣のQRコードに切り替えられます。
  • 大きく表示している間のラベル付与は、いま表示している1件だけに付きます。「付与完了にする」は、閉じて一覧に戻ってから押します。
  • チェックボックスを押したまま、ほかのQRコードの上へなぞると、通ったQRコードをまとめて選べます（パソコンのマウス操作です）。
  • 「未入力の項目で絞り込み」「QRコードの生成日で絞り込み」で、一覧を絞れます。

注意点

  • 本社名とホール名は、セットで付きます。ホール名を先に選ぶと、本社名が自動で入ります。
  • カードの背景が薄い緑のときは、4項目がすべて入っています。ただし、自動で付与完了にはなりません。4項目が空のままでも、「付与完了にする」は押せます。
  • 「選択QRのラベルを消去」と「選択QR削除」は、実行直後の通知に出る「元に戻す」から戻せます。
手順7

印刷するQRコードを選ぶ

できること

  • 印刷するQRコードを探して、選びます。

操作方法

  1. 探す条件（納品日・本社名・ホール名・商品名・取り込み日時）を選びます。1つだけでも、組み合わせても使えます。
  2. 「検索」を押します。すべて見るときは「全件表示」、条件を消すときは「条件をクリア」を押します。
  3. 印刷するQRコードのチェックを入れます。
  4. 選び終わったら、一覧の下の「手順8」へ進みます。

そのほかの操作

  • 間違えて付与完了にしたQRコードは、選んで「付与未完了にする」を押すと、③に戻ります。
  • 納品日を変えたいときは、QRコードを選び、日付を入れて「選択QRの納品日を一括変更」を押します。チェックを入れたQRコードだけが変わり、印刷にも変更後の日付が使われます。
  • チェックボックスを押したまま、ほかのQRコードの上へなぞると、通ったQRコードをまとめて選べます（パソコンのマウス操作です）。

注意点

  • 条件を選んだだけでは、一覧は変わりません。必ず「検索」を押してください。
  • ここに出るのは、③で「付与完了にする」を押したQRコードだけです。
  • 本社名を選ぶと、ホール名の候補がその本社のものに絞られます。ホール名を先に選ぶと、本社名が自動で入ります。
手順8

A4 PDFで印刷する

できること

  • 手順7で選んだQRコードを、A4のPDFにします。

操作方法

  1. 手順7で、印刷するQRコードにチェックを入れます。
  2. 「4個（2行×2列）」か「6個（3行×2列）」を選びます。
  3. 「A4 PDF作成」を押します。
  4. 保存されたPDFを、印刷します。

注意点

  • QRコードを選ぶまで、「A4 PDF作成」は押せません。
  • ページは、納品日とホール名ごとに分かれます。
  • PDFを作ると、選んだQRコードは「⑤ 印刷済み」へ移ります。
  • 「⑤ 印刷済み」に残るのは、ホールごとに最近の2回分だけです。それより古いものは、自動で消えます。

手順9

印刷済みQRコードを確認する

できること

  • PDFにしたQRコードを、ホール名ごとに確認します。
  • もう一度印刷したいQRコードを、手順7に戻せます。

操作方法

  1. 探す条件を選んで、「検索」を押します。すべて見るときは「全件表示」を押します。
  2. 戻したいQRコードのチェックを入れます。ホールごとにまとめて選ぶときは「このホールを全選択」を押します。
  3. 「手順7に戻す」を押します。
  4. ④ 印刷準備で選び直して、PDFを作ります。

そのほかの操作

  • チェックボックスを押したまま、ほかのQRコードの上へなぞると、通ったQRコードをまとめて選べます（パソコンのマウス操作です）。

注意点

  • 「検索」か「全件表示」を押すまで、一覧は出ません。
  • 残るのは、ホールごとに最近の2回分だけです。それより古いものは、自動で消えます。
  • 条件の選び方は、手順7と同じです。
接続設定

送信先と接続を設定する

できること

  • スマホのURLを、メールでPCに送るための設定をします。

操作方法

  1. 「Google Apps Script URL」「転送トークン」「送信先Mail」を入力します。
  2. 「接続設定を保存」を押します。
  3. 「接続テスト」を押して、「接続OK」と出るか確認します。

注意点

  • 転送トークンは、システム管理者に確認してください。
  • ここが未設定だと、手順3でURLを送れません。

保存設定

データを自動で保存する

できること

  • データを、この端末のブラウザだけでなく、サーバー（Cloudflare D1）にも自動で保存します。

操作方法

  1. 「D1保存用トークン」を入力します。
  2. 「D1設定を保存」を押します。
  3. すぐに保存したいときは「今すぐD1に保存」、保存されている件数を見たいときは「D1の件数を確認」を押します。

注意点

  • トークンは、システム管理者に確認してください。
  • トークンを入れないときは、この端末のブラウザにだけ保存します。
  • QRコードの画像は保存しません。URLなどの情報だけを保存します。
  • トークンを空にして保存すると、D1への保存をやめます。
未設定（この端末のブラウザにだけ保存）
マスタ設定

本社名・ホール名を登録する

できること

  • 本社名とホール名の一覧を登録します。登録すると、ラベル付与や検索で選べるようになります。

操作方法

  1. 下の入力欄に、1行ずつ「本社名,ホール名」の形で入力します。
  2. 同じ本社に複数のホールがあるときは、本社名を同じにして、行を分けます。
  3. 「本社名 / ホール名リストを保存」を押します。

注意点

  • 本社名とホール名は、「,」（カンマ）で区切ります。
  • 形が違う行は、登録されません。
  • 保存すると、いまの一覧が、入力した内容に置き換わります。
本社名A,ホールA1 本社名A,ホールA2 本社名B,ホールB1 本社名B,ホールB2
データ設定

バックアップと初期化をする

できること

  • QRコードのデータを、ファイルに保存したり、読み込んだり、すべて消したりします。

操作方法

  1. 保存するとき：「バックアップを書き出す」を押します。
  2. 元に戻すとき：「バックアップを読み込む」を押して、保存したファイルを選びます。
  3. すべて消すとき：「全データ削除」を押し、確認の画面で「すべて削除する」を押します。

注意点

  • 「バックアップを読み込む」と、いまのQRコードのデータが、ファイルの内容に置き換わります。
  • 読み込めなかったときは、いまのデータは変わりません。
  • 「全データ削除」も、実行直後の通知に出る「元に戻す」から戻せますが、念のため先にバックアップを書き出してください。
